# Reference implementation

These sources were exported from a single Arch/Hyprland + YNDX-0004 installation.
They have been anonymised and **are not a one-command installer**. Examples use
placeholder paths and addresses. See the root README before adapting anything.
No credentials, device identifiers, logs, firmware or backup data are included.
The Yandex.Station upstream project is not vendored; consult its own license and
version before applying the small documented event metadata patch.
